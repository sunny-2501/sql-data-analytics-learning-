# SQL Learning Journey

This repository documents my SQL learning and practice journey for Data Analytics.

I am currently learning SQL using Microsoft SQL Server and SQL Server Management Studio (SSMS). I use this repository to store my practice queries, mistakes, corrected queries, HackerRank problems, and SQL concepts as I progress toward Data Analyst-level SQL skills.

---

## About This Repository

The purpose of this repository is to:

- Build strong SQL fundamentals
- Practice SQL regularly
- Improve problem-solving skills
- Understand SQL from a Data Analyst perspective
- Practice real-world analytical queries
- Track my learning progress
- Prepare for SQL interviews and Data Analyst roles

Some of my earlier SQL files contain multiple topics in the same file because they were created while I was learning the basics.

Instead of deleting that work, I have kept those queries as part of my learning journey.
